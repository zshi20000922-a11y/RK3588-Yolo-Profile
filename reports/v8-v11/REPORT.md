# RK3588 YOLOv8 / YOLO11 INT8 板端 Profile

测试日期：2026-09-02；RKNN Toolkit/Runtime 2.3.2；RKNPU driver 0.9.8；静态输入 640×640、batch 1、INT8；NPU 1 GHz。四个模型均使用同一 SHA-256 为 `25b0b030...c4c3c4` 的 500 张校准集。

## 结论

四个模型均为 Rockchip 优化的 9-output 图：每个尺度分别输出 DFL box、80 类 sigmoid score 和 score-sum。所有计算层均在 RK3588 NPU 执行，没有 CPU fallback。YOLOv8/11 不是端到端输出，CPU 后处理包含 DFL 解码、阈值过滤、NMS 和坐标还原。

## 推荐

- 最低延迟和最大吞吐：YOLOv8n，单核 56.90 FPS、三核 156.84 FPS。
- n 模型中更重视精度：YOLO11n 比 v8n AP50-95 高 0.02209，但单核吞吐低约 16.9%。
- s 模型中 YOLO11s 精度比 v8s 高 0.02115，但单核 FPS 低约 12.3%。若吞吐优先选择 v8s，精度优先选择 11s。
- 四个 INT8 模型的 AP50-95 损失约 0.025～0.029，需要结合业务容忍度。YOLO26 输出图与后处理协议不同，不将它的精度和本组结果混表比较。
